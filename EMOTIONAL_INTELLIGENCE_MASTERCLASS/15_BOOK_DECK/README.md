# عرض «الذكاء العاطفي للمهندسين»

عرض تقديمي (127 شريحة) للكتاب «الذكاء العاطفي للمهندسين: دليل عملي لإتقان المهارات»، بنفس الشكل البصري لعرضي الحلقتين E01 وE02.

- العرض المنشور: https://claude.ai/artifact/YcTu9bcd7En4GsDfniabDq
- البنية: حالة واحدة (نقد علني في اجتماع تنسيق) يعود إليها كل فصل؛ خريطة الأجزاء والفصول أعلى كل شريحة؛ كل فصل = افتتاحية (السؤال والخطوات) ← شرائح مرقمة بالخطوة ← الحالة ← خلاصة وتمارين وسؤال يقود للفصل التالي؛ وفي النهاية «الحالة من أولها لآخرها».
- البناء: `cd _build && python3 make_deck.py` ← يكتب `deck/project/deck.json` و`deck/project/slides/*.html`.
- `_build/lib.py`: الألوان والخطوط والمساعدات (نص، بطاقات، جداول، عقد ورسوم)، والتنقل: `chapter` و`step` و`opener` و`case` و`closer` وشريط التقدم. الرسوم الخطية مأخوذة من `07_BOOK_LED_EPISODES/E01|E02/_build/art.py`.
- `_build/part1.py` … `part4.py`: الشرائح وملاحظات المتحدث لكل جزء من الكتاب.
- الصور (Wikimedia Commons): كاخال، Gray's Anatomy، دافنشي (ملكية عامة)، سقراط (Eric Gaba، CC BY-SA 2.5). روابطها في `_build/assets.json` كأصول داخل العرض.
- كل معلومة تحمل موضعها: «ص» = جولمان (عالم المعرفة 262)، «p.» = MoM / CC / KZ، «L» = NVC. الأمثلة الهندسية غير المنسوبة والتشبيهات من إعداد الكتاب ومعلّمة كذلك.
