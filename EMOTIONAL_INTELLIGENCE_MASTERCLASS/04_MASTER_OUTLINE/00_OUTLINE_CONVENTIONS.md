# 00_OUTLINE_CONVENTIONS — قواعد المخطط التفصيلي
**PHASE 5 — MASTERCLASS STRUCTURE (للسلسلة).** المخطط = **نبضات** لا سكريبت. يُبنى فوق `03_INTEGRATED_FRAMEWORK` (10 حلقات، 66 مشهدًا) دون تغيير الحدود.

## 1. شكل كل مشهد في المخطط
```
### E#-## · العنوان (من – إلى)
- الوظيفة: لماذا المشهد موجود في القصة
- النبضات: [زمن نسبي] نوع · ما يحدث
- الجملة المفتاحية (مسودة): «…»   ← ليست نصًا نهائيًا
- نقطة التحول: ما الذي يتغير عند المشاهد
- الانتقال: كيف نخرج إلى المشهد التالي
- المصدر/الوسم: …
```

**أنواع النبضات:**
| النوع | المعنى |
|---|---|
| VISUAL | ما يُرى قبل أي كلام |
| STORY | فعل درامي |
| VOICE | فكرة يقولها المقدم، تُصاغ في السكريبت |
| INNER | الصوت الداخلي لشخصية (نص حركي) |
| ASK | سؤال مباشر للمشاهد + وقفة |
| DO | تمرين |
| REVEAL | كشف |
| SOURCE | بطاقة مصدر صغيرة |
| TURN | نقطة التحول |
| HOOK | الخطاف |

## 2. قواعد الصياغة (تسري على السكريبت لاحقًا)
| القاعدة | التطبيق |
|---|---|
| **المشهد قبل المصطلح** | المصطلح يظهر **بعد** أن يعيش المشاهد الفكرة، ثم يُترجم فورًا للعامية |
| **≤ 6 تعريفات صريحة في السلسلة** | اليقظة (E3)، النوبة الانفعالية (E2)، الاحتياج (E4)، المحادثة الحاسمة (E7)، Dark EQ كمصطلح تعليمي (E8)، الإطار النهائي (E10) |
| **الاقتباس من الكتب الإنجليزية** | يُقال بالعربية كـ«ترجمة عمل»، والنص الأصلي في بطاقة المصدر فقط |
| **الاقتباس من Goleman** | من الترجمة العربية (عالم المعرفة 262) بالصفحة |
| **الأرقام والدراسات** | فقط ما يُنسب («بحسب ما ينقله الكتاب»). **ممنوع:** IQ≈20% كحقيقة، والمارشميللو كسبب، و«12 ملّي ثانية» للإنسان، وإحصاءات أمريكية مؤرخة |
| **الأسماء في القصص المنقولة** | تُحكى كما في المصدر أو بلا اسم؛ لا تُخترع تفاصيل غير موجودة |
| **الشخصيات المعاصرة** | خيالية من تأليف المشروع؛ تُقدَّم كقصص توضيحية لا كحالات حقيقية |
| **عتمان** | [FICTIONAL_CASE_STUDY]؛ السلوك المؤكد من الويب فقط (F01–F06)؛ **لا حوار حرفي**؛ لا تشخيص؛ رسم تعبيري |
| **لغة Dark EQ** | «ده سلوك تلاعبي» لا «ده شخص نرجسي»؛ السلوك المنفرد ليس تلاعبًا؛ العدسة السداسية قبل أي وصف |
| **D3** | «أنا مسؤول عن ردّي… وده مش معناه إن اللي حصل ماحصلش». **ممنوع:** «محدش يقدر يزعلك غير نفسك» عند وجود أذى |
| **الإطار النهائي** | [PROJECT INTEGRATED FRAMEWORK] — لا يُنسب لأي مؤلف |
| **السلامة** | لا تفاصيل اعتداء أو انتحار أو أدوية؛ الموارد في بطاقة النهاية فقط |

## 3. صوت المقدم (دليل مختصر — يُفصَّل في PHASE 10)
- **دليل لا أستاذ:** «تعالى نفهم اللي بيحصل جوانا».
- جمل قصيرة، أسئلة مباشرة، وقفات حقيقية (2–3 ثوانٍ بعد كل ASK).
- **يخفض صوته في:** الكشف الأوسط (E5)، والسؤال الهادئ (E8)، والجملة الأخيرة (E10).
- **يبطئ في:** التمارين الحية (E3)، وجمل الحدود (E5، E9).
- **خفة ظل مسموحة في:** E1، E6. **ممنوعة في:** مشاهد عتمان، وE8، وقصة إيرين.
- **يحكي قصص المصادر بصوته** (أم جيسكا، الساموراي، قطار طوكيو، الطيار، إيرين، دفتر الشيكات، مريض اللوزتين) ويذكر اسم المؤلف مرة واحدة، لأن الإسناد جزء من الأمانة.
