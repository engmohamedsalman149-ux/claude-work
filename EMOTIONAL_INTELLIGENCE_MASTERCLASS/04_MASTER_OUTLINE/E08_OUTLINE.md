# E08_OUTLINE — نفس المهارة · ~14.5 دقيقة
**السؤال:** «إيه اللي يحصل لما حد يفهمني… ويستخدم الفهم ده ضدي؟ وأعرف إزاي إنه نمط مش موقف؟»
**العمود الفقري:** سؤال هادئ ← نفس المهارة واتجاه مختلف ← صِف ولا تشخّص ← عتمان 3 ← الصمت حول السلطة ← هشام (موقف) مقابل عادل (نمط) + العدسة ← «عادي لوحده» ثم جدار الأنماط.
**المنحنى العاطفي:** يقظة هادئة ← ثقل (عتمان) ← وضوح ← **طمأنينة بالأداة** (لا ذعر).
**قاعدة الحلقة:** لا موسيقى إثارة. لا تعميم على فئات. كل نمط = «الجملة ← متى تصبح نمطًا ← كيف تتعرف».
